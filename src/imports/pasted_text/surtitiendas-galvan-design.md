Diseña una aplicación e-commerce moderna, profesional y responsive llamada “Surtitiendas Galván”, orientada principalmente a dispositivos móviles pero adaptable también a versión web/desktop.

Tipo de negocio: almacén y tienda online multiproducto que vende artículos de papelería, belleza, cuidado capilar, cuidado facial, libros, pinturas y otros productos para hogar y uso cotidiano.

Objetivo del diseño

Crear una experiencia de compra sencilla, rápida, visual y confiable. El usuario debe poder descubrir productos, buscar, filtrar, agregar al carrito y realizar una compra con pocos pasos.

El estilo debe transmitir una tienda accesible, organizada y moderna, evitando una apariencia demasiado lujosa. Debe sentirse como un gran almacén digital donde se encuentran productos de diferentes categorías.

Estilo visual
Diseño limpio, moderno y comercial.
Mucho espacio en blanco.
Tarjetas de producto con bordes ligeramente redondeados.
Sombras muy suaves.
Iconografía simple y consistente.
Fotografías grandes y claras de los productos.
Tipografía moderna y muy legible, como Inter, Poppins o similar.
Diseñar un sistema de colores coherente con la marca Surtitiendas Galván.
Usar un color principal llamativo para botones y acciones importantes.
Usar colores secundarios suaves para diferenciar las categorías.
Mantener buen contraste y accesibilidad.
